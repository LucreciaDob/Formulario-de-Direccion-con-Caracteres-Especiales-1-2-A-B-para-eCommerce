# 📦 Formulario de Dirección con Soporte para Números Especiales  

En muchos formularios de direcciones, solo se permiten números enteros, lo que genera problemas para usuarios cuyas viviendas contienen valores intermedios como **"1620 1/2"**. Esto puede dificultar la entrega de paquetes y causar frustración.  

## 🚀 Características  
✅ **Opción "Sin número"** para direcciones sin numeración.  
✅ **Opción "Mi número tiene más valores"** para direcciones como `"123A"`, `"45 1/2"`, etc.  
✅ **Fácil integración** en formularios de e-commerce y checkout.
